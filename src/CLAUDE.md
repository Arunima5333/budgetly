# Project Instructions

This is Budgetly, a monthly budget planner built with Angular 7, TypeScript, Bootstrap and CSS, using mock data and no backend.

## Rules

- This project uses Angular 7: use NgModules, *ngIf and *ngFor. Do not use standalone components, @if/@for or signals.
- Follow the existing Angular project structure.
- Follow the existing coding style.
- Inspect existing code before making changes.
- Make only the changes required for the feature.
- Do not modify unrelated files.
- Do not install new packages without asking first.
- Keep the implementation simple and readable.
- Consider edge cases.
- Run relevant tests after making changes.
